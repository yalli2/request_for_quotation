# 다인에듀 B2B 교육 프로그램 견적 사이트

yalli2 GitHub 학습 사이트(158개 저장소)를 분석해 기업·기관용 **프로그램 75개 · 패키지 18개**로 정리한 견적 사이트입니다.

- 사이트 주소: https://yalli2.github.io/request_for_quotation/

## 기능
- **패키지 및 가격**: 언어별 패키지 9개 / 분야별 패키지 9개, 계약 기간 토글(월간·분기·반기·연간)에 따라 1명·1개월 가격 표시
- **운영 방식 비교**: 셀프 학습형 · 블렌디드 · 실시간 화상 · 출강
- **견적 계산기**: 인원, 계약 기간, 운영 방식, 개별 프로그램(언어별·분야별 보기, 검색)
- **견적서**: 인쇄·PDF 저장, 텍스트 복사, 견적 링크 공유(선택 내용이 주소에 저장됨)

## 가격 바꾸는 법
| 파일 | 내용 |
|---|---|
| `pricing.js` | 분야별 단가, 인원별 할인, 다과목 할인, 계약 기간 할인(월간 0% → 분기 5% → 반기 10% → 연간 15%), 운영비, 정기 고객 혜택, 최대 할인 한도 |
| `data.js` | 프로그램 목록(저장소 연결), 패키지 구성과 할인율 |

## 계산 방식
1. 정가 = 프로그램 단가 합계 × 인원
2. 인원 할인 → 패키지(또는 다과목) 할인 → 계약 기간 할인 순서로 곱해서 적용 (합계 최대 50%)
3. 강사 운영비 = 운영 방식 단가 × 반 수(인원 ÷ 15, 올림), 계약 기간 할인 적용
4. 월 환산 × 계약 개월 수 = 공급가액, 부가세 10% 별도
